# Excel-data-cleaning
## Overview
A data cleaning project using Microsoft Excel and Power Query to identify and resolve data quality issues, improve data consistency, and prepare datasets for accurate analysis.

## Tools Used
- Microsoft Excel
- Power Query

## Data Source
- Kaggle

## Cleaning Tasks
- Removed duplicate records
- Handled missing or blank values
- Standardized data formats
- Transformed columns

## Outcomes
- Improved data accuracy and consistency.
- Reduced duplicate records.
- Addressed missing values to improve data completeness.
- Standardized data formats for easier interpretation.
- Improved dataset structure and readability.
- Prepared the dataset for further analysis and visualization.
